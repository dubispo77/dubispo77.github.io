Política de Privacidade

Hub Eduardo · aplicativo pessoal · atualizada em 15 de setembro de 2026

O Hub Eduardo é um aplicativo de uso pessoal, desenvolvido e mantido por Eduardo Romano Bispo para organizar a própria agenda, tarefas e finanças. Ele não é oferecido comercialmente e não possui base de usuários além do próprio desenvolvedor.

Dados que o aplicativo acessa

Quando o usuário autoriza a conexão com a Conta do Google, o aplicativo acessa exclusivamente:

  • eventos dos calendários do Google Agenda da conta autorizada, incluindo título, data, horário, descrição e local;
  • a lista de calendários da conta, para saber em qual calendário cada compromisso deve ser criado ou atualizado.

O aplicativo não acessa e-mails, contatos, arquivos, fotos ou qualquer outro serviço do Google.

Para que esses dados são usados

Os dados do calendário são usados com uma única finalidade: manter os compromissos sincronizados entre o Google Agenda e o Hub, nos dois sentidos. Compromissos criados ou editados no Hub são gravados no calendário correspondente, e alterações feitas no Google Agenda aparecem no Hub.

Onde os dados ficam

As informações sincronizadas ficam armazenadas em um banco de dados privado (Supabase), acessível apenas mediante autenticação da própria conta. As credenciais de acesso ao Google são guardadas de forma restrita no mesmo ambiente e usadas somente para renovar a sessão de sincronização.

Compartilhamento

Nenhum dado obtido pelas APIs do Google é vendido, alugado, compartilhado com terceiros, usado para publicidade, usado para criar perfis de marketing ou utilizado para treinar modelos de inteligência artificial. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Retenção e exclusão

Os dados permanecem armazenados enquanto a conexão com o Google estiver ativa. Ao desconectar a conta dentro do Hub, as credenciais de acesso são apagadas e a sincronização é interrompida. A autorização também pode ser revogada a qualquer momento em myaccount.google.com/permissions.
